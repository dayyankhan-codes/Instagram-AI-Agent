# 📷 Instagram AI Agent

An AI-powered assistant built with Python, Streamlit, and Google's Gemini API to help photographers create better Instagram posts.

## 🚀 Features

- 📸 Analyze uploaded images using AI
- ⭐ Rank photos by quality
- 🖼️ Suggest the best carousel order
- ✍️ Generate Instagram captions
- 🎵 Recommend trending audio
- 🎨 Generate Lightroom Classic editing values
- 🎭 Suggest masking adjustments

## 🛠️ Built With

- Python
- Streamlit
- Google Gemini API
- Pillow
